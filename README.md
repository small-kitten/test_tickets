Этот проект создан для создания и администрирования заявок о проблемах

Для запуска веб-приложения на Windows требуется:
    1.В BIOS/UEFI должна быть включена виртуализация
    2.Иметь docker desktop
    3.Включить поддержку wsl (wsl --install)
    4.Запустить docker desktop
    5.Копировать репозиторий (git clone <URL>)
    6.Перейти в корень проекта (папка test), и запустить (docker compose up -d --build)

После запуска на вашем локальном порте 8080 появиться веб-приложение с протоколом http
                        (http://127.0.0.1:8080)
